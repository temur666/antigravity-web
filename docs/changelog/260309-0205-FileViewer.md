# File Viewer - 文件查看器功能

## 修改模块
- `main.js` (后端)
- `frontend/src/utils/markdown.ts`
- `frontend/src/components/FileViewer/` (新增)
- `frontend/src/components/ChatPanel/ChatPanel.tsx`

## 功能说明

### 后端 - 文件读取 API
- 新增 `GET /api/file?path=<relative-path>` 端点
- 支持读取项目目录内的任意文本文件
- 安全措施：`realpath` 防目录穿越，5MB 文件大小限制
- 可配置根目录：`FILE_ROOT` 环境变量，默认为项目根目录

### 前端 - 文件链接拦截
- 自定义 `marked` 的 `renderer.link`：将 `file://` 协议链接转为带 `data-file-path` 属性的可点击链接
- ChatPanel 中通过事件委托拦截 `.file-link` 点击，打开文件查看器

### 前端 - FileViewer 模态框
- 支持 Markdown 文件渲染（复用现有 `renderMarkdown`）
- 支持代码文件语法高亮（复用现有 `highlight.js`）
- 其他文本文件以纯文本展示
- 支持 ESC 键和点击遮罩关闭
- 移动端以 bottom sheet 形态展示
