# 260310-0130 YOLO 自动驾驶模式

## 概述

实现了 YOLO (You Only Live Once) 自动驾驶模式，支持无人值守的长时间 AI 任务执行。

## 新增文件

| 文件 | 职责 |
|------|------|
| `scripts/yolo.js` | 主循环 — 通过 gRPC 与 LS 对话，自动回复模板消息 |
| `scripts/yolo-done.js` | Hook — AI 调用触发熔断 + Telegram 通知 |
| `.agents/workflows/yolo.md` | Workflow 文档 — 使用说明和参考模板 |

## 功能特性

- **自动回复**: AI 完成一轮后，自动发送固定模板消息让 AI 继续工作
- **完成 Hook**: AI 执行 `yolo-done.js` → 写标记文件熔断主循环 → Telegram 通知
- **超时保护**: 默认 2 小时，可通过 `--timeout` 调整
- **日志记录**: 每次运行的完整对话记录存到 `logs/yolo-*.log`
- **指数退避重连**: gRPC 连接断开后自动重试，退避最大 30 秒
- **自动批准**: 自动处理 WAITING 状态的命令执行请求
- **连续错误保护**: 连续 10 次错误后自动停止

## 架构

```
参考文档.md → yolo.js (gRPC) → LS → AI 工作
                 ↑                      |
                 |  自动回复模板          |
                 ←←←←←←←←←←←←←←←←←←←←←←
                                        |
                              AI 执行 yolo-done.js
                                        |
                              .yolo-done 标记文件
                                        |
                              yolo.js 熔断 + Telegram 通知
```
