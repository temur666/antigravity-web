# URL 路由化 — 对话直链访问

## 模块
- `frontend/src/utils/url.ts`（新建）
- `frontend/src/store/app-store.ts`
- `frontend/src/App.tsx`

## 改动内容

将对话访问从纯 localStorage 恢复升级为 History API URL 路由：

- `/` → 对话列表
- `/chat/<conversationId>` → 直达某个对话

### 具体改动

1. **新建 `utils/url.ts`** — 提供 `getConversationIdFromUrl()` 和 `pushConversationUrl()` 两个纯函数
2. **修改 `app-store.ts`** — 初始化时 URL 优先于 localStorage；`selectConversation` 和 `setActiveConversation` 同步更新 URL
3. **修改 `App.tsx`** — 添加 `popstate` 监听器，浏览器前进/后退时同步对话切换

### 效果

- 通过链接可直接访问某个对话，无需依赖 localStorage
- 浏览器前进/后退正常工作
- 服务端无需改动（已有 SPA fallback）
